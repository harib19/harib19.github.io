Methodology

Baseline · Dr. RTL (reproduced)

Single-clock optimizer

  • Released analyzer and optimizer prompts and 47-skill library, used verbatim.
  • Loop: whole-design STA → critical-path analysis → skill-based rewrite → SEC → score → promote.
  • Score: 0.5·WNS + 0.35·TNS + 0.15·Area, over the whole design.
  • Correctness gate: SEC only. No model of clock domains or crossings.
  • Tool substitution: Design Compiler → Yosys + OpenSTA; Jasper SEC → EQY.
Proposed · Aegis

Multi-clock optimizer

  • CDC shield: crossing classification, lock tiers, formally proven Gray-code contracts.
  • Per-domain selection: timing deficits and region quotas per clock domain.
  • Generation: 65 skills (47 from Dr. RTL + 18 CDC-aware). 5 candidates per region, confined to an edit envelope.
  • Verification: checksum/envelope → lint → multi-clock simulation → CDC re-check → EQY.
  • Score: S = Σ wd(αWd + βTd) / Σ wd + γ·f(A), wd = fd/fmax, with adaptive α, β, γ.
